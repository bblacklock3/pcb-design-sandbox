# Decision log

Every chosen value gets an entry: what was decided, why, and the datasheet numbers
behind it. Newest first.

Format:

```
## YYYY-MM-DD — <decision>
**Chose:** <value/part>
**Because:** <reasoning with numbers>
**Source:** <datasheet section / part note>
```

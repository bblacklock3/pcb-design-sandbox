## Role on this board

Sole controller. Five motor channels (EN = PWM on TIM3 for the leaves, TIM1 for yaw; PH = GPIO),
five IPROPI analog inputs on ADC1, four encoder timer-capture inputs, one I²C bus to the drivers,
SWD. LQFP64, 0.5 mm pitch.

## Placement constraints

- **One 100 nF per VDD pin, pad-to-pad within budget, same side, no via in the supply leg.**
  VDD1–4 sit on four different package edges, so the caps spread the cluster in all four
  directions — inherent to LQFP64. The return is a via to the In1 GND plane, which the vault
  requires to be continuous under the part.
- **VCAP_1 cap adjacent to pin 30** (east edge, 1 mm from VDD2) — stagger it along the edge so
  its courtyard clears the VDD2 cap.
- **Crystal Y1 directly at pins 5/6 (south edge)**, load caps (33 pF — the X32258MSB4SI is a
  CL = 20 pF part) flanking it, GND case pins to the plane; keep the oscillator loop short and
  away from the motor nets.
- NRST: 10 k pull-up, 100 nF to GND and the reset button close to pin 7; the SWD header (6-pin:
  +3V3, SWDIO, SWCLK, GND, NRST, SWO/PB3) is DNP bare PTH — place it where an ST-Link lead reaches.
- **The west edge faces the board rim** — keep it for nothing that needs to reach a part;
  the pin map already does this (SWD PA13/PA14 are N/W, I²C on PB8/PB9 W — slow signals).
- SWD J2 is DNP bare PTH — place where an ST-Link lead can reach, not under anything.

## Pin assignment is a layout constraint

Which pin a signal gets decides which package edge it escapes from. The vault MCU Pinout page
assigns by edge (EN_leaf1/2 and PH_leaf1/2 north toward leaf1/2 drivers; EN/PH/IPROPI leaf3/4
east/south; IPROPI only on ADC-capable E/S pins because ADC1 has no north-edge pins; all four
leaf EN on TIM3 so one TRGO triggers the current-sense scan). **Re-pinning is a vault change**,
not a layout convenience — check the edge map in that page before moving anything.

Provisional pins chosen in the schematic (see `MIGRATION.md` → decisions owed): I2C1 PB8/PB9,
DRV_nSLEEP PC5, nFAULT PC0/PC1/PC2/PC10 + PC12 (yaw), RC_OUT PB6/PB7/PA10/PA11 + PB13 (yaw).

Silicon facts that bind: PB2 is BOOT1 (kept empty); PA13/PA14 are SWD; PH0/PH1 are the HSE
pins; no ADC on the north edge.

## Routing constraints

- Decoupling legs point-to-point cap → pin; only the return leg via to the plane.
- IPROPI_* are analog single-ended: route over the GND plane, away from OUT1/OUT2 and VM.
- Oscillator: no signals under Y1/C19/C20; GND guard from the plane.

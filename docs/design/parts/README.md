# Part constraint notes

One file per part, distilled from the datasheet in `docs/datasheets/`. A part may not
be placed in the circuit until its note exists here. Template:

```markdown
# <Part> — design notes

Source: docs/datasheets/<file>.pdf

## Role in this design
## Pinout (as used here)
## Electrical limits that matter here
## Layout constraints
## Gotchas
```
